# Context Frames for Skill Orchestration: Active Operational Patterns

**Version:** 1.0  
**Date:** January 2025  
**Type:** Yang/Active Application of Context Frames  
**Timeline:** Long-term Vision (Post Expert Agent Development)  

## Vision & Core Concept

Context frames as **operational patterns for skill orchestration** - enabling sophisticated coordination of skills across subsystems based on epistemic context requirements. This represents the **yang/active** application of context frames, providing dynamic routing and coordination intelligence.

### Philosophical Foundation

Context frames become **operational coordination patterns** that guide how skills are selected, combined, and orchestrated across the Epi-Logos system:

- **Database Coordination**: Context frames map to specific database combinations (e.g., 5/0 → Notion + Neo4j)
- **Epistemic Workflow Patterns**: Different frames enable different types of thinking and processing
- **Cross-Subsystem Orchestration**: Frames coordinate multi-agent workflows across expert subsystems
- **Adaptive Skill Selection**: Dynamic skill routing based on contextual requirements

## Operational Intelligence Patterns

### Frame-Based Skill Selection

**Intelligent Routing Algorithm**:
1. **Context Analysis**: Determine required epistemic context from user query
2. **Frame Mapping**: Map context requirements to appropriate context frame(s)
3. **Database Selection**: Activate relevant databases based on frame mapping
4. **Skill Coordination**: Select and coordinate skills within frame constraints
5. **Cross-Frame Integration**: Manage workflows spanning multiple frames

### Adaptive Orchestration

**Dynamic Frame Switching**:
- **Trigger Conditions**: Complexity thresholds, knowledge gaps, user preferences
- **Transition Logic**: Smooth handoffs between frames with context preservation
- **Feedback Loops**: Frame effectiveness monitoring and adaptation

**Multi-Agent Coordination**:
- **Frame-Specific Experts**: Each subsystem expert optimized for specific frames
- **Cross-Frame Communication**: Protocols for inter-frame knowledge transfer
- **Conflict Resolution**: Handling competing frame recommendations
